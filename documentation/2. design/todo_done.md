| AGD-007 | The domain is declared, not written: agency adopts `mwanachama-backend-catalog`'s blueprint/spec/operations format — objects, fields and indexes declared as JSON instead of row structs, routes and MCP tools declared as operations and dispatched by reflection, `spec` and the generic store lifted into `mwanachama-backend-shared` | 2026-09-24 | Full decision record: [todo_details/AGD-007.md](todo_details/AGD-007.md). Prompted by the user pointing at `mwanachama-backend-catalog` and asking for agency to be converted to "the exact same format", with whatever is reusable moved to shared because the other backends follow. Four decisions taken in a Q&A before any code: convert **completely** (storage, HTTP and MCP, not just the data layer); move **`spec` and a generalized store** into `mwanachama-backend-shared` (filed there as S18/S19), with catalog switching onto them in the same pass so the shape is proved by two consumers before fifteen more follow; adopt **`<instance>_<module>_<table>`**, so this repo's tables become `agency_agency_goals` and siblings — named by the user with the mwanachama-2 Supabase project open beside the `agency_catalog_*` tables already there; and keep the format's reference documentation in **shared's** `documentation/2. design/` (S20), since it is an org-wide standard from here on. Implementation filed as **AG37–AG45** on [../3. implementation/todo.md](../3.%20implementation/todo.md) — nothing started yet. AG44/AG45 go past this repo's own code: the converted tables have to exist in mwanachama-2, and [`developer/documentation/4. qa/mwanachama-wakala/agency.json`](../../../mwanachama-developer/documentation/4.%20qa/mwanachama-wakala/agency.json) — the company written as an agency, 9 roles / 10 objectives / 35 role assignments — is the document that has to land in them. Three open bugs are folded into the conversion rather than fixed before it, since their fix sites are being rewritten anyway: **AG35** (`NextCode`'s unguarded read-modify-write) and **AG34** (the Update/Delete TOCTOU) into AG39, **AG33** (the composite tool's silent key overwrite) into AG41. Known costs recorded rather than discovered later: `routes.ResourceNames` has no equivalent in a literal-path operations spec and goes away, `routes.Route` becomes `httpwire.Route` for all five consuming repos, every agency route carries a gating action for the first time, and nothing in catalog mints a `Code`, so the code sequence needs its own answer. Four questions left open in the record: whether draft scoping is expressible as ordinary declared fields, whether the attachment tables fill roles or are domain-only objects, what the rename does about wakala-api's per-instance on-demand provisioning, and whether `AgencySnapshot` (AG36, dead since `PromoteDraft` was deleted) is declared at all or retired here. |
